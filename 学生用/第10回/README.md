密度・比重の定義から、実データの比較、Eと強度、節・目切れ、加工・接合、表面処理と保守へ進みます。演習では、計算できる量と、その情報だけでは決められない性能を区別します。

| ハンドアウト | 本編の問題・解説 |
|---|---|
| 問1 比例モデルと残差 | 17・18枚目 |
| 問2 Eと変形・破壊 | 21・22枚目 |
| 問3 曲げ応力とMOR | 25・26枚目 |
| 問4 穴と正味断面 | 29・30枚目 |
| 問5 重ね接着と平均応力 | 34・35枚目 |
| 問6 栽培容器の架台と保守 | 43・44枚目 |

問1は本編で示した実データを使いますが、175Gは比較用の仮定モデルです。問2～5の数値と問6の場面は自作の仮想例です。自己確認用で、正式な提出課題・配点・締切は授業の指示を確認してください。

中学校技術への題材提案、材料力学の定義・計算、データ評価の考え方をつなげています。動画の実再生時間は89:58です。演習・休憩は合計36:50です。学習者の実際の所要時間とは異なります。合成音声と切替字幕を使用しています。

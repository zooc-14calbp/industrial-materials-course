# 第10回 木材の強さ・密度・加工と接合

**学修時間の目安：約99分**（動画 89:16 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（11頁）](10_ハンドアウト.pdf)を用意します。7～8頁に密度の基準と接着部の力を考える記録欄があります。
2. [授業動画（89:16）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson10-listening/lesson10-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](10_授業スライド.pdf) ／ [PowerPoint](10_授業スライド.pptx)で図と数値を確認します。

動画は89:16、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](10_授業スライド.pdf)の46～51枚目、または[ハンドアウト](10_ハンドアウト.pdf)の9～10頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド6～13：全乾密度・基本密度、比重と曲げ強さのグラフ。データの基準と対象を確認します。
- スライド20・25：木材の三方向、三点曲げ試験の幅と高さ。
- スライド31～35：木材・接着層・界面と、接着面の平均応力や力の作用線。
- スライド41～44：屋外で使う教材台の水分管理と維持。

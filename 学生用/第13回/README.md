問い、比較条件、測定方法、記録、改善案を順に検討します。第12・14枚の数値は授業用の模擬データで、実測値ではありません。同一試料を3回読んだ例を材種全体の性能へ一般化しないでください。家庭での破壊試験は求めません。

動画は合成音声を使用。実再生時間90:34には、説明音声32:19、考える時間56分、休憩2分と画面切替を含みます。演習ではノートに問い・条件・結果・未確認事項を書き、必要に応じて一時停止してください。実際の学習時間は人によって異なります。

## 思考時間の使い方

第13～15回はハンドアウトを別途配布していません。スライドを開き、次の問いへの回答をノートに記録してください。以下は既存の自己確認・振り返りの案内で、追加の提出課題ではありません。音声で案内する分数と次の画面までの時間が異なる箇所があります。動画の進行に合わせて切り上げず、必要に応じて一時停止し、記録してから解説へ進んでください。

| スライド | 考えること・ノートに残すもの |
|---|---|
| 5（解説6） | 厚い木の板と薄い樹脂の板の差を材質だけで説明できるか。変える条件・そろえる条件を図と理由で示す。 |
| 10・12～14 | スライド10の四つの項目で記録欄を作る。模擬データの平均・最小・最大と1.0 mm以下の基準を比較し、同一試料3回から言える範囲を書く。 |
| 18～20 | 観察・原因候補・追加確認・改善案を整理する。棚の改善案を二つ選び、効果・不利点・再確認する条件を書く。 |
| 21～23 | 第12回の案について、分かったこと・未確認事項・仮定・次の確認方法を区別し、比較計画の不足条件を追記する。 |

自己確認は正式課題とは別です。正式課題IIIの設問・提出方法・締切・配点は授業の指示に従ってください。

# Chapter 13（第13回）　比較・検査・改善を計画する

**この章の流れ**　比較の問いと条件 → 測定と記録 → 差とばらつきの判断 → 検査・点検から改善へ → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:54 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 13.1　比較の問いと条件

**問い**　材質を比べる試験と、製品案を比べる試験では、何を変えるでしょうか。

**結論の見通し**　変える要因とそろえる条件を分け、計画図に比較の目的を残します。

スライド1～7枚目 ／ 動画 00:00から

### Section 13.2　測定と記録

**問い**　誰が測っても比較できる記録には、何が必要でしょうか。

**結論の見通し**　測定量・器具・読み方・条件をそろえ、破壊を前提にしない確認を考えます。

スライド8～11枚目 ／ 動画 20:57から

### Section 13.3　差とばらつきの判断

**問い**　平均に差があるとき、材料の違いが原因と言えるでしょうか。

**結論の見通し**　ばらつき、試料の単位、測定条件を確認し、理論との差の原因を切り分けます。

スライド12～16枚目 ／ 動画 34:01から

### Section 13.4　検査・点検から改善へ

**問い**　完成後の検査と使用中の点検を、どう改善に結び付けるでしょうか。

**結論の見通し**　観察結果から改善案を立て、効果・代償と再確認の方法を記録します。

スライド17～25枚目 ／ 動画 52:03から

## Section 13.5　試作の検査と評価の記録（視聴後・約10分）

**問い**　比べた結果を改善に使うため、記録に何を残すでしょうか。

**結論の見通し**　測定方法と比較条件を明らかにし、結果から次の試験を計画します。

指導要領との接続を、[スライドPDF](13_授業スライド.pdf)の26～31枚目、または[ハンドアウト](13_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

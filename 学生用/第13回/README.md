# Chapter 13（第13回）　比較・検査・改善を計画する

**この章の流れ**　比較の問いと条件 → 測定と記録 → 差とばらつきの判断 → 検査・点検から改善へ → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 13.1　比較の問いと条件

**問い**　材質を比べる試験と、製品案を比べる試験では何を変えますか。

**結論の見通し**　比較の目的を決め、変える要因とそろえる条件を示します。

スライド2～8枚目 ／ 動画 01:07から（1枚目は章全体の導入）

### Section 13.2　測定と記録

**問い**　別の人が同じように測るには、何を記録しておきますか。

**結論の見通し**　測定位置、器具、読み方を定め、結果と一緒に残します。

スライド9～13枚目 ／ 動画 21:00から

### Section 13.3　差とばらつきの判断

**問い**　平均値に差があるとき、材料の違いが原因だと言えるでしょうか。

**結論の見通し**　ばらつきと試料の単位を確認し、測定やモデルの影響も調べます。

スライド14～19枚目 ／ 動画 34:14から

### Section 13.4　検査・点検から改善へ

**問い**　検査や使用中の点検を、次の試作にどう生かしますか。

**結論の見通し**　変更の効果と不利な点を予想し、同じ条件で確かめ直します。

スライド20～29枚目 ／ 動画 52:22から

## Section 13.5　試作の検査と評価の記録（視聴後・約10分）

**問い**　試作を改善するために、測定結果と一緒に何を残しますか。

**結論の見通し**　比較条件と測定方法を記録し、次に確かめる問いを決めます。

指導要領との接続を、[スライドPDF](13_授業スライド.pdf)の30～36枚目、または[ハンドアウト](13_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

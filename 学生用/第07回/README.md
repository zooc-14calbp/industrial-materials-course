# Chapter 7（第7回）　高分子の構造とプラスチックの性質

**この章の流れ**　高分子の鎖と加熱 → 結晶部分・非晶部分と温度 → 物性表と透明な部品 → 誤った説明を条件に戻して直す → 指導要領との接続・確認クイズ。

**学修時間の目安：約95分**（動画 85:21 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（13頁）](07_ハンドアウト.pdf)を用意します。既存の想定問題8問に加え、9～10頁に結晶・非晶と試験片比較の記録欄があります。
2. [授業動画（85:21）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson07-listening/lesson07-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](07_授業スライド.pdf) ／ [PowerPoint](07_授業スライド.pptx)で図と数値を確認します。

動画は85:21、合成音声・切替字幕付きです。必要に応じて一時停止してください。さらに復習する場合は、視聴後に5分程度、熱可塑性と熱硬化性、結晶部分と架橋、同じ力と断面積での応力を、自分の言葉と図で振り返ります。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 7.1　高分子の鎖と加熱

**問い**　再加熱で成形しやすい樹脂と、硬化後に再成形しにくい樹脂はどう違うでしょうか。

**結論の見通し**　熱可塑性と熱硬化性の違いを、分子鎖の動きと架橋から説明します。

スライド1～9枚目 ／ 動画 00:00から

### Section 7.2　結晶部分・非晶部分と温度

**問い**　ガラス転移と融解では、材料のどこで何が変わるでしょうか。

**結論の見通し**　結晶と非晶の区別から、温度による変形と補強・添加の効果を考えます。

スライド10～16枚目 ／ 動画 06:22から

### Section 7.3　物性表と透明な部品

**問い**　透明な候補を、どの条件で比較すればよいでしょうか。

**結論の見通し**　外観だけでは材種は決まらず、寸法・荷重と物性表の試験条件をそろえて判断します。

スライド17～25枚目 ／ 動画 12:13から

### Section 7.4　誤った説明を条件に戻して直す

**問い**　試験片の断面積が違うと、同じ力でも結果はどう変わるでしょうか。

**結論の見通し**　応力・ひずみ・伸びを区別し、樹脂の構造や用途まで根拠を添えて説明します。

スライド26～42枚目 ／ 動画 28:01から

## Section 7.5　樹脂の加熱と成形を説明する（視聴後・約10分）

**問い**　外観が似た樹脂を、生徒とどう見分けて考えるでしょうか。

**結論の見通し**　名称や見た目だけで判断せず、加熱時の振る舞いと用途を関係付けます。

指導要領との接続を、[スライドPDF](07_授業スライド.pdf)の43～48枚目、または[ハンドアウト](07_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

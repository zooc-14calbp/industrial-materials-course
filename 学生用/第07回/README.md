# Chapter 7（第7回）　高分子の構造とプラスチックの性質

**この章の流れ**　高分子の鎖と加熱 → 結晶部分・非晶部分と温度 → 物性表と透明な部品 → 誤った説明を条件に戻して直す → 指導要領との接続・確認クイズ。

**学修時間の目安：約97分**（動画 87:01 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 7.1　高分子の鎖と加熱

**問い**　加熱すると再び成形できる樹脂と、硬化する樹脂はどう違うでしょうか。

**結論の見通し**　分子鎖の動きと、鎖同士をつなぐ架橋に注目します。

スライド2～10枚目 ／ 動画 00:26から（1枚目は章全体の導入）

### Section 7.2　結晶部分・非晶部分と温度

**問い**　ガラス転移と融解では、鎖のどの部分に何が起きるでしょうか。

**結論の見通し**　非晶部分の動きやすさと、結晶部分の規則的な並びの変化を分けます。

スライド11～18枚目 ／ 動画 06:43から

### Section 7.3　物性表と透明な部品

**問い**　透明な教材カバーの候補を、どの条件で比べればよいでしょうか。

**結論の見通し**　物性表の試験条件を読み、部品の厚さ・荷重・使う温度と照らします。

スライド19～28枚目 ／ 動画 12:58から

### Section 7.4　誤った説明を条件に戻して直す

**問い**　ヤング率が大きい試験片は、同じ力でいつも伸びが小さいでしょうか。

**結論の見通し**　応力・ひずみ・伸びを分け、材料の性質と試験片の寸法を確かめます。

スライド29～46枚目 ／ 動画 29:12から

## Section 7.5　樹脂の加熱と成形を説明する（視聴後・約10分）

**問い**　見た目が似た樹脂の加熱時の違いを、どう説明するでしょうか。

**結論の見通し**　温めたときの変化を、鎖の動き、硬化の有無、用途と結び付けます。

指導要領との接続を、[スライドPDF](07_授業スライド.pdf)の47～53枚目、または[ハンドアウト](07_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

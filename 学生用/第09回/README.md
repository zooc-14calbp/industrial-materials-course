# Chapter 9（第9回）　木材の構造・方向・水分

**この章の流れ**　木材の三方向と組織 → 含水率と水の存在場所 → 方向による寸法変化 → 比較と予測の条件 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 9.1　木材の三方向と組織

**問い**　木口・板目・柾目を見分けると、木材の何が分かるでしょうか。

**結論の見通し**　観察面と繊維・放射・接線の三方向を区別します。

スライド2～12枚目 ／ 動画 01:09から（1枚目は章全体の導入）

### Section 9.2　含水率と水の存在場所

**問い**　水の質量が同じでも、含水率が異なるのはなぜでしょうか。

**結論の見通し**　全乾質量を分母にし、水の場所と二つの指標を区別します。

スライド13～24枚目 ／ 動画 17:13から

### Section 9.3　方向による寸法変化

**問い**　湿度が変わると、板の幅と長さは同じ割合で変わるでしょうか。

**結論の見通し**　方向、含水状態、拘束を確かめ、寸法変化や反りを説明します。

スライド25～37枚目 ／ 動画 44:03から

### Section 9.4　比較と予測の条件

**問い**　木材の変化や予測の精度は、どの条件で比べればよいでしょうか。

**結論の見通し**　変化の原因を分け、未知の親板を使う予測は親板単位で評価します。

スライド38～45枚目 ／ 動画 01:12:11から

## Section 9.5　木材の方向と水分を観察する（視聴後・約10分）

**問い**　木材の方向と水分の影響を、生徒とどう観察するでしょうか。

**結論の見通し**　面と測定方向を示し、湿度や測定時刻を記録します。

指導要領との接続を、[スライドPDF](09_授業スライド.pdf)の46～52枚目、または[ハンドアウト](09_ハンドアウト.pdf)の8～9頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

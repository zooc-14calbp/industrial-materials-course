# Chapter 9（第9回）　木材の構造・方向・水分

**この章の流れ**　木材の三方向と組織 → 含水率と水の存在場所 → 方向による寸法変化 → 比較と予測の条件 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:37 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 9.1　木材の三方向と組織

**問い**　木口・板目・柾目を区別すると、何が見えるでしょうか。

**結論の見通し**　観察面と木材の三方向を分け、節の周囲や細胞の並びを確かめます。

スライド1～11枚目 ／ 動画 00:00から

### Section 9.2　含水率と水の存在場所

**問い**　同じ水の量でも、含水率の値が違うのはなぜでしょうか。

**結論の見通し**　分母を全乾質量にそろえ、細胞壁内の水と自由水、繊維飽和点と平衡含水率を区別します。

スライド12～22枚目 ／ 動画 17:04から

### Section 9.3　方向による寸法変化

**問い**　乾燥や湿度の変化で、板の幅と長さは同じ割合で変わるでしょうか。

**結論の見通し**　方向・含水状態・拘束の違いから、扉のすき間や反りを説明します。

スライド23～34枚目 ／ 動画 43:54から

### Section 9.4　比較と予測の条件

**問い**　木材と樹脂の変化や、AIの予測精度は何をそろえて評価できるでしょうか。

**結論の見通し**　変化の原因と測定条件を区別し、未知の試料や由来を分けて予測を点検します。

スライド35～41枚目 ／ 動画 01:11:55から

## Section 9.5　木材の方向と水分を観察する（視聴後・約10分）

**問い**　木の板の向きと湿度は、製作品にどう関わるでしょうか。

**結論の見通し**　木材の方向と含水状態を示し、条件をそろえた観察に結び付けます。

指導要領との接続を、[スライドPDF](09_授業スライド.pdf)の42～47枚目、または[ハンドアウト](09_ハンドアウト.pdf)の8～9頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

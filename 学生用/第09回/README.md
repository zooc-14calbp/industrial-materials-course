# 第9回 木材の構造・方向・水分

**学修時間の目安：約100分**（動画 89:37 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（10頁）](09_ハンドアウト.pdf)を用意します。6～7頁に含水率と方向別の寸法変化を考える記録欄があります。
2. [授業動画（89:37）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson09-listening/lesson09-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](09_授業スライド.pdf) ／ [PowerPoint](09_授業スライド.pptx)で図と数値を確認します。

動画は89:37、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](09_授業スライド.pdf)の42～47枚目、または[ハンドアウト](09_ハンドアウト.pdf)の8～9頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド4：L・R・Tの方向と断面。
- スライド12・17：乾量基準の含水率、繊維飽和点（FSP）、平衡含水率（EMC）。
- スライド25・28・33：方向別の寸法変化、反りの概念図、計算式と記号。図と数値は学習用モデルです。
- スライド36・37：AIの仮想的な予測精度と、未知の親板で評価するためのデータ分割。

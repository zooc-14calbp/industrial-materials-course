木材の三方向と断面、細胞壁と水、含水率と密度、方向別の寸法変化、拘束と接合を扱います。AIの仮想的な精度表示について、評価指標と親板単位のデータ分割を点検します。

動画は合成音声を使用。実再生時間89:38には説明音声50:13、演習・記録37分、休憩2分と画面切替を含みます。必要に応じて一時停止してください。学習者の実際の所要時間は異なります。

ハンドアウトの問1はスライド13・14、問2は21・22、問3は32・33、問4は36・37に対応します。出口課題は39です。計算の係数やAIの成績は授業用の仮想例として区別してください。自己確認問題は正式な提出課題とは別です。正式な設問・締切・配点は授業の指示に従ってください。

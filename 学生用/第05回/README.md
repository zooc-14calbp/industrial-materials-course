# 第5回　金属の構造と性質

**学修時間の目安：約93分**（動画 82:52 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

1. [ハンドアウト](05_ハンドアウト.pdf)を用意する。全18頁。量と記号、本編の計算と比較、接続・想定問題1–5、化学結合の参考6頁、AI評価の記録欄です。
2. [授業動画（82:52）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson05-figures/lesson05-video.mp4)を見ながら、自分の説明を記録する。
3. [スライドPDF](05_授業スライド.pdf)で図・数値を確かめ、説明を見直す。[PowerPoint](05_授業スライド.pptx)にも対応原稿を入れています。

動画の実再生時間は82:52です。説明音声51:22、演習・休憩31:00、画面切替を含みます。合成音声・切替字幕付き。必要に応じて一時停止してください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](05_授業スライド.pdf)の57～62枚目、または[ハンドアウト](05_ハンドアウト.pdf)の17～18頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド14：密度を原子数・原子1個の質量・格子の体積から考える。ハンドアウト2頁。
- スライド15・24・45：δ鉄の名称と、軸方向の伸びδを区別する。化学の図のδ＋・δ−は部分電荷。
- スライド31：同じ体積と同じ軸方向剛性を分けて比べる。ハンドアウト4頁。
- スライド35・48–49：母材ごとに分けて、未知の母材でAIを評価する。ハンドアウト16頁。
- スライド40–49：接続・想定問題1–5。ハンドアウト5–9頁。実際の採用試験の転載・出題予告ではありません。AIの検討文は授業用の想定例です。
- スライド51–56：化学結合の任意参考。動画本編には含めず、ハンドアウト10–15頁にも保持。

PowerPoint・PDFは本編50枚、化学結合の任意参考6枚、指導要領と確認クイズ6枚の計62枚です。Eはヤング率、ρは密度、kは軸方向剛性です。記号は式の対象と一緒に読み、共通一覧の「δ：たわみ」をこの回へ一律に当てはめないでください。

さらに復習する場合は、8分を目安に記録を見直します。①ヤング率と降伏強さ、②同じ体積と同じ剛性、③未知の試験片と未知の母材を各2分で説明し、残り2分で学校の授業でどう説明するかをノートにまとめてください。理解に応じて一時停止や復習時間を増やして構いません。

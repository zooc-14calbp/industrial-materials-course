# Chapter 5（第5回）　金属の構造と性質

**この章の流れ**　金属の結合と結晶 → 組織と塑性変形 → 合金・用途・物性データ → 説明と予測を検証する → 指導要領との接続・確認クイズ。

**学修時間の目安：約95分**（動画 84:29 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 5.1　金属の結合と結晶

**問い**　原子の結び付きや並び方から、金属の何が分かるでしょうか。

**結論の見通し**　電子の広がりから伝導を考え、単位格子の質量と体積から密度を求めます。

スライド2～15枚目 ／ 動画 00:52から（1枚目は章全体の導入）

共有結合、金属結合、イオン結合、水素結合を復習するには、スライド55～60枚目またはハンドアウト10～15頁を参照してください。

### Section 5.2　組織と塑性変形

**問い**　金属を強化すると、弾性域でも伸びにくくなるでしょうか。

**結論の見通し**　結晶粒や相と転位の動きを考え、ヤング率と降伏強さを区別します。

スライド16～26枚目 ／ 動画 17:05から

### Section 5.3　合金・用途・物性データ

**問い**　密度の小さい金属を選べば、部品も同じ割合で軽くなるでしょうか。

**結論の見通し**　同じ体積と同じ軸方向剛性を分け、物性値を測った状態も確かめます。

スライド27～38枚目 ／ 動画 29:55から

### Section 5.4　説明と予測を検証する

**問い**　金属についての説明や、AIの予測をどう確かめるでしょうか。

**結論の見通し**　説明は図・式・条件に戻って点検し、予測は母材を分けて評価します。

スライド39～54枚目 ／ 動画 43:33から

## Section 5.5　金属の性質を用途につなぐ（視聴後・約10分）

**問い**　金属の使い分けを、生徒が観察したことからどう説明するでしょうか。

**結論の見通し**　加工や使用の場面を起点に、観察した性質と材料の構造をつなぎます。

指導要領との接続を、[スライドPDF](05_授業スライド.pdf)の61～67枚目、または[ハンドアウト](05_ハンドアウト.pdf)の17～18頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド15：密度を原子数・原子1個の質量・格子の体積から考える。ハンドアウト2頁。
- スライド17・26・49：δ鉄の名称と、軸方向の伸びδを区別する。化学の図のδ＋・δ−は部分電荷。
- スライド34：同じ体積と同じ軸方向剛性を分けて比べる。ハンドアウト4頁。
- スライド38・52–53：母材ごとに分けて、未知の母材でAIを評価する。ハンドアウト16頁。
- スライド44–53：接続・想定問題1–5。ハンドアウト5–9頁。実際の採用試験の転載・出題予告ではありません。AIの検討文は授業用の想定例です。
- スライド55–60：化学結合の任意参考。ハンドアウト10–15頁にも図を収録しています。

PowerPoint・PDFは本編54枚、化学結合の任意参考6枚、指導要領と確認クイズ7枚の計67枚です。Eはヤング率、ρは密度、kは軸方向剛性です。記号は式の対象と一緒に読み、共通一覧の「δ：たわみ」をこの回へ一律に当てはめないでください。

さらに復習する場合は、8分を目安に記録を見直します。①ヤング率と降伏強さ、②同じ体積と同じ剛性、③未知の試験片と未知の母材を各2分で説明し、残り2分で学校の授業でどう説明するかをノートにまとめてください。理解に応じて一時停止や復習時間を増やして構いません。

動画の時間は実再生時間の目安で、演習・記録・休憩を含みます。必要に応じて一時停止し、自分で図・途中式・理由を記録してください。第4回の断面二次モーメントと第5回の化学の復習には、動画本編に含まれない任意参考資料があります。

動画には合成音声と字幕トラックを収録しています。外部字幕や目次など、普段の学習では使わない資料は各回の「補助資料」に置いています。音声だけで復習する場合も、図の説明ではスライドを併用してください。

自己確認問題は、正式な提出課題とは別です。正式な設問・提出方法・締切・配点は授業の指示に従ってください。

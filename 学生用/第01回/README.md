# 第1回　材料を選ぶための見方

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト](01_ハンドアウト.pdf)を用意する。全9頁。本編の記入欄1～4頁、密度と説明の記録欄5～6頁、確認クイズ7～8頁、記号一覧9頁です。
2. [授業動画（89:58）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-90min/lesson01-video.mp4)を見ながら、自分の説明を記録する。
3. [スライドPDF](01_授業スライド.pdf)で図・数値を確かめ、説明を見直す。[PowerPoint](01_授業スライド.pptx)にも対応原稿を入れています。

動画の実再生時間は89:58です。説明音声77:01、演習・休憩12:34と画面切替を含みます。合成音声・切替字幕付き。必要に応じて一時停止してください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](01_授業スライド.pdf)の39～45枚目、または[ハンドアウト](01_ハンドアウト.pdf)の7～8頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。身近な製品の材料を思い出す導入の問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド13：密度の数値例。ハンドアウト5頁に計算と説明を記録する。
- スライド32：たわみから強度を言い切れるかを点検する。ハンドアウト6頁を使う。AIの実利用は不要です。
- スライド4・6・35：[問題と個別ルーブリック](../評価課題/README.md)を一緒に読む方法を確認する。

評価課題は4回構成の共有案です。配点・提出期限・提出先は、担当教員の正式な告知を確認してください。動画内の自己確認は、個別の提出課題ではありません。

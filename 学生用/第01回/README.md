# Chapter 1（第1回）　材料を選ぶための見方

**この章の流れ**　材料を比べる出発点 → 棚板の選び方 → 栽培容器と使用環境 → 観察から選択の根拠へ → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 1.1　材料を比べる出発点

**問い**　同じ用途でも、何を比べればよいでしょうか。

**結論の見通し**　強度・剛性・質量などを分け、用途と制約から比較の観点を選びます。

スライド2～15枚目 ／ 動画 01:21から（表紙は1枚目）

### Section 1.2　棚板の選び方

**問い**　棚板を替えるとき、材料のほかに何を変えられるでしょうか。

**結論の見通し**　寸法・支え方・荷重を図にし、一つずつ条件を変えて比べます。

スライド16～24枚目 ／ 動画 31:20から

### Section 1.3　栽培容器と使用環境

**問い**　屋内用の案を屋外へ移すと、何を見直す必要があるでしょうか。

**結論の見通し**　水・日射・期間と中身の重さを考え、接合や修理も含めて選びます。

スライド25～33枚目 ／ 動画 50:41から

### Section 1.4　観察から選択の根拠へ

**問い**　観察したことと、その結果から下す判断はどう違うでしょうか。

**結論の見通し**　測定値と解釈を分け、比較表とレポートに判断の根拠を残します。

スライド34～42枚目 ／ 動画 01:10:25から

## Section 1.5　用途と条件から考える材料選択（視聴後・約10分）

**問い**　学校の製作活動では、何を決めてから材料を比べるでしょうか。

**結論の見通し**　使う人・場所・要求を先に整理し、試作品の評価を形や材料の改善に返します。

指導要領との接続を、[スライドPDF](01_授業スライド.pdf)の43～50枚目、または[ハンドアウト](01_ハンドアウト.pdf)の7～8頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。身近な製品の材料を思い出す導入の問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

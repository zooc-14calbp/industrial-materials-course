# Chapter 11（第11回）　三材料の物性値と計算による比較

**この章の流れ**　比較に使う物性値の条件 → 同じ断面での三材料比較 → 同じ質量と同じたわみ → 計算結果と適用範囲 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 11.1　比較に使う物性値の条件

**問い**　表の密度やヤング率を計算に使う前に、何を確かめますか。

**結論の見通し**　単位、試料の方向、含水状態、試験条件を記録します。

スライド2～9枚目 ／ 動画 01:12から（1枚目は章全体の導入）

### Section 11.2　同じ断面での三材料比較

**問い**　同じ断面で材料を替えると、応力・たわみ・質量はどう変わるでしょうか。

**結論の見通し**　このはりモデルでは、応力は同じで、たわみと質量は物性値で変わります。

スライド10～19枚目 ／ 動画 15:37から

### Section 11.3　同じ質量と同じたわみ

**問い**　同じ質量や同じたわみを求めると、比較はどう変わるでしょうか。

**結論の見通し**　そろえる量を一つ決め、必要な断面寸法から計算し直します。

スライド20～26枚目 ／ 動画 36:20から

### Section 11.4　計算結果と適用範囲

**問い**　試験値やAIの計算を、どこまで使用判断に使えるでしょうか。

**結論の見通し**　式・単位・入力値を点検し、試験値と設計上の許容値を区別します。

スライド27～42枚目 ／ 動画 49:16から

## Section 11.5　材料データと高校情報の接点（視聴後・約10分）

**問い**　物性値を表にするとき、材料名と数値のほかに何を残しますか。

**結論の見通し**　単位・試験・状態を記録して、比べられる値を選びます。

指導要領との接続を、[スライドPDF](11_授業スライド.pdf)の43～49枚目、または[ハンドアウト](11_ハンドアウト.pdf)の13～14頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

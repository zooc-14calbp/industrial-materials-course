# 第11回 三材料の物性値と計算による比較

**学修時間の目安：約100分**（動画 89:53 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（15頁）](11_ハンドアウト.pdf)を用意します。11～12頁に比較条件と入力値の意味を考える記録欄があります。
2. [授業動画（89:53）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson11-listening/lesson11-video.mp4)を視聴し、図・式と説明を対応させて記録します。
3. [スライドPDF](11_授業スライド.pdf) ／ [PowerPoint](11_授業スライド.pptx)で図と数値を確認します。

動画は89:53、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](11_授業スライド.pdf)の39～44枚目、または[ハンドアウト](11_ハンドアウト.pdf)の13～14頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

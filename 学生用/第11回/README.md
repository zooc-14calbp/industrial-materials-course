# Chapter 11（第11回）　三材料の物性値と計算による比較

**この章の流れ**　比較に使う物性値の条件 → 同じ断面での三材料比較 → 同じ質量と同じたわみ → 計算結果と適用範囲 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:53 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 11.1　比較に使う物性値の条件

**問い**　表の密度やヤング率を使う前に、何を確認するでしょうか。

**結論の見通し**　試料・方向・含水状態・測定条件を押さえ、実測に基づく値と仮定値を区別します。

スライド1～8枚目 ／ 動画 00:00から

### Section 11.2　同じ断面での三材料比較

**問い**　外力と断面が同じなら、材料を替えたときに何が変わるでしょうか。

**結論の見通し**　この静定モデルでは応力を同じ式で求め、たわみと質量にはEと密度の違いが表れます。

スライド9～17枚目 ／ 動画 15:29から

### Section 11.3　同じ質量と同じたわみ

**問い**　比較の基準を変えると、選択の結論はどう変わるでしょうか。

**結論の見通し**　断面寸法を計算し直し、同じ断面・質量・たわみの結果を別々に読みます。

スライド18～23枚目 ／ 動画 36:08から

### Section 11.4　計算結果と適用範囲

**問い**　曲げ強さやAIの計算結果は、そのまま使用の判断に使えるでしょうか。

**結論の見通し**　試験値と許容値を区別し、寸法誤差、比較条件、式と単位を検証します。

スライド24～38枚目 ／ 動画 48:54から

## Section 11.5　材料データと高校情報の接点（視聴後・約10分）

**問い**　異なる資料の物性値を表にするとき、材料名と数値のほかに何が必要でしょうか。

**結論の見通し**　試験・単位・状態を記録し、比較できるデータかを判断してから可視化します。

指導要領との接続を、[スライドPDF](11_授業スライド.pdf)の39～44枚目、または[ハンドアウト](11_ハンドアウト.pdf)の13～14頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

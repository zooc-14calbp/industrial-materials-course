# Chapter 15（第15回）　材料選択の再検討と学びの統合

**この章の流れ**　初回の材料比較表に戻る → 数値と使用条件を統合する → 新しい条件で選び直す → 専門理解を学校の学びへつなぐ → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:55 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（12頁）](15_ハンドアウト.pdf)を用意します。9頁に材料選択の根拠と見直しの記録欄があります。
2. [授業動画（89:55）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson15-listening/lesson15-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](15_授業スライド.pdf) ／ [PowerPoint](15_授業スライド.pptx)で内容を確認します。

動画は89:55、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 15.1　初回の材料比較表に戻る

**問い**　第1回の材料選択を、今ならどんな根拠で説明できるでしょうか。

**結論の見通し**　三材料を共通の枠組みで見直し、物性の名称・単位・条件を結び付けます。

スライド1～8枚目 ／ 動画 00:00から

### Section 15.2　数値と使用条件を統合する

**問い**　計算の順位と、実際に使うときの判断が違うのはどんな場合でしょうか。

**結論の見通し**　断面・使用環境・加工・維持を加え、グラフの傾向と個別の判断を分けます。

スライド9～14枚目 ／ 動画 23:50から

### Section 15.3　新しい条件で選び直す

**問い**　前提が変わったら、どの結論を更新し、どこを保留するでしょうか。

**結論の見通し**　追加で必要な情報を明示し、計算・データ・定性的判断を課題の説明にまとめます。

スライド15～19枚目 ／ 動画 47:27から

### Section 15.4　専門理解を学校の学びへつなぐ

**問い**　材料選択の考え方を、生徒が自分で使う問いにするには何が必要でしょうか。

**結論の見通し**　用途から選択・評価・改善へ進む手順を説明し、学びの記録を残します。

スライド20～25枚目 ／ 動画 01:10:02から

## Section 15.5　材料選択と教育課程の見直し（視聴後・約10分）

**問い**　条件や教育課程が変わったとき、何を基準に説明を更新するでしょうか。

**結論の見通し**　選択の根拠を問い直し、現行の指導内容、審議案、授業者の提案を区別します。

指導要領との接続を、[スライドPDF](15_授業スライド.pdf)の26～32枚目、または[ハンドアウト](15_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

# Chapter 15（第15回）　材料選択の再検討と学びの統合

**この章の流れ**　初回の材料比較表に戻る → 数値と使用条件を統合する → 新しい条件で選び直す → 専門理解を学校の学びへつなぐ → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（13頁）](15_ハンドアウト.pdf)を用意します。冒頭の「節の見取り図」から進み、演習とクイズは本文に印刷されたページ番号で確認します。9頁に材料選択の根拠と見直しの記録欄があります。
2. [授業動画（89:58）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-06-chapters09-15/lesson15-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](15_授業スライド.pdf) ／ [PowerPoint](15_授業スライド.pptx)で内容を確認します。

動画は89:58、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 15.1　初回の材料比較表に戻る

**問い**　第1回の材料選択を、いまならどんな根拠で説明できますか。

**結論の見通し**　材料名に、物性の名称・単位・比較条件を添えます。

スライド2～9枚目 ／ 動画 00:49から（1枚目は章全体の導入）

### Section 15.2　数値と使用条件を統合する

**問い**　計算の順位と、使うときの判断が違うのはどんな場合ですか。

**結論の見通し**　断面・環境・加工・維持を加え、数値で言える範囲を確かめます。

スライド10～16枚目 ／ 動画 23:44から

### Section 15.3　新しい条件で選び直す

**問い**　前提が変わると、どの結論を更新し、どこを保留しますか。

**結論の見通し**　変わった条件の影響を見直し、不足するデータを示します。

スライド17～22枚目 ／ 動画 47:23から

### Section 15.4　専門理解を学校の学びへつなぐ

**問い**　材料選択の考え方を、生徒自身が使う問いにするには何が必要ですか。

**結論の見通し**　用途から選択・評価・改善へ進む活動と、学びの記録を用意します。

スライド23～29枚目 ／ 動画 01:10:02から

## Section 15.5　材料選択と教育課程の見直し（視聴後・約10分）

**問い**　材料の条件や教育課程が変わるとき、何を根拠に説明を更新しますか。

**結論の見通し**　材料選択の根拠を見直し、現行の指導内容・審議資料・授業案を分けます。

指導要領との接続を、[スライドPDF](15_授業スライド.pdf)の30～37枚目、または[ハンドアウト](15_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

10月公表の審議まとめも、現行の指導内容と区別して読みます。 [文部科学省「次期学習指導要領等に向けた審議まとめ」](https://www.mext.go.jp/b_menu/shingi/chukyo/chukyo3/004/gaiyou/1292164_00001.htm)

第1回の材料選択を、計算、グラフ、使用環境、維持管理の観点から再検討します。数値は授業用の仮定に基づく計算値と区別して扱います。

動画は合成音声を使用。実再生時間91:34には、説明音声24:19、考える時間65分、休憩2分と画面切替を含みます。問いと理由をノートに記録し、必要に応じて一時停止してください。

## 思考時間の使い方

第13～15回はハンドアウトを別途配布していません。スライドを開き、次の問いへの回答をノートに記録してください。以下は既存の自己確認・振り返りの案内で、追加の提出課題ではありません。音声で案内する分数と次の画面までの時間が異なる箇所があります。動画の進行に合わせて切り上げず、必要に応じて一時停止し、記録してから解説へ進んでください。

| スライド | 考えること・ノートに残すもの |
|---|---|
| 3・13・14 | 第1回の比較表を取り出し、残せる根拠、修正する根拠二つ、未確認条件と確認方法を一つ書く。初回の記録がなければ、当初の印象と現在の案を区別する。 |
| 7（解説8） | Eと応力、比重と個々の強度、樹脂の再成形についての三つの説明を、条件付きの正しい文へ書き換える。 |
| 16（解説17） | 樹脂を想定より高温で使う場合、室温のEによる計算の扱い、追加情報、変更できる設計条件、判断を保留する条件を書く。 |
| 19・22・23 | 単位・方向・支持条件と根拠の範囲を点検する。条件付きで説明できる特徴、変わった判断や深まった根拠、生徒への比較の問い、今後の確認事項を残す。 |

自己確認は正式課題とは別です。正式課題の設問・提出方法・締切・配点は授業の指示に従ってください。

第1〜15回とは別の発展学修です。スライド・ハンドアウト・音声・字幕・動画を対応させています。

1. [ハンドアウト（8頁）](発展B_ハンドアウト.pdf)を用意します。
2. [授業動画（65:06）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-extension-abc/extensionB-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](発展B_先端素材・新素材.pdf) ／ [PowerPoint](発展B_先端素材・新素材.pptx)で内容を確認します。

積層方向と荷重の向き、材料予測におけるロットの分け方を考えます。

動画は65:06、合成音声・切替字幕付きです。必要に応じて一時停止してください。図は授業用の模式図、計算・試験の数値は仮想例を含みます。

## 節の見取り図

### B.1　構造と製法

**問い**　複合材や積層造形の性質は、方向や製法でどう変わるか。

**見通し**　繊維・母材・積層方向と荷重の関係を確かめます。

スライド1～11枚目 ／ 動画 00:00から

### B.2　用途と維持

**問い**　架台に新素材を使うなら、どの条件で従来の案と比べるか。

**見通し**　必要な機能から出発し、耐久性や回収まで比較します。

スライド12～17枚目 ／ 動画 16:31から

### B.3　試験データと予測

**問い**　試験で得た値やAIの推薦は、どの材料に適用できるか。

**見通し**　試料の状態とロットの分け方を見て、適用範囲を判断します。

スライド18～26枚目 ／ 動画 34:52から

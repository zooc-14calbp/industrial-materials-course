縄文土器と瓦、結合・焼結・欠陥、硬さと靭性、熱衝撃、宇宙と医療の利用例を、用途と製法・構造・使用条件から比較します。以前の授業スライドのセラミックス部分も参照して再構成しました。

合成音声を使用。実再生75:31には説明24:12、読解・記録49分、休憩2分と切替を含みます。必要に応じて一時停止してください。図は授業用の模式図、計算・試験の数値は仮想例です。宇宙はスペースシャトルの歴史的事例、医療は部品の用途例として扱います。

自己確認は正式な提出課題とは別です。正式課題の指示に変更はありません。

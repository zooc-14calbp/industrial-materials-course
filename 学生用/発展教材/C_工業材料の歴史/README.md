## 節の見取り図

### C.1　資料の読み方

**問い**　利用の変化を、どんな史料から確かめられるか。

**見通し**　資料が示す範囲と、地域や時期による違いを確かめます。

スライド1～6枚目 ／ 動画 00:00から

### C.2　木材・焼き物・金属

**問い**　木材、瓦、鉄の製造と利用は、どこで結び付くか。

**見通し**　道具、燃料、流通、建物の構造から材料どうしの関係をたどります。

スライド7～21枚目 ／ 動画 12:15から

### C.3　樹脂と材料の役割分担

**問い**　新しい材料が加わると、既存の材料との役割分担はどう変わるか。

**見通し**　一つの製品で複数の材料が働く例を、時代を越えて比べます。

スライド22～33枚目 ／ 動画 40:45から

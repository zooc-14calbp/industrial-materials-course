木材・焼き物・金属・樹脂の利用史を、用途・資源・製法・輸送・修理から読みます。四材料の併存と相互の影響、歴史資料の証拠と推測の区別を重視します。縄文の木材・土器、瓦屋根、たたら製鉄、初期のプラスチックなどを事例にします。

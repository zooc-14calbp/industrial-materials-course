# Chapter 3（第3回）　力とモーメントのつり合い

**この章の流れ**　はりのモデルと支点反力 → 断面の力と線図 → 荷重位置と支え方の影響 → 荷重分布とデータの刻み → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 3.1　はりのモデルと支点反力

**問い**　支点が止める動きから、どんな反力を図に描けばよいでしょうか。

**結論の見通し**　外力図を作り、力とモーメントのつり合いから反力を求めます。

スライド2～16枚目 ／ 動画 00:50から（表紙は1枚目）

### Section 3.2　断面の力と線図

**問い**　はりを途中で切り出すと、どの力とモーメントが見えるでしょうか。

**結論の見通し**　切断位置と符号をそろえ、せん断力図と曲げモーメント図を対応させます。

スライド17～27枚目 ／ 動画 22:10から

### Section 3.3　荷重位置と支え方の影響

**問い**　荷重をずらしたり、片側を固定したりすると、線図はどう変わるでしょうか。

**結論の見通し**　せん断力図の符号付き面積を使い、最大曲げモーメントが生じる位置を確かめます。

スライド28～37枚目 ／ 動画 38:32から

### Section 3.4　荷重分布とデータの刻み

**問い**　総荷重が同じなら、どの載せ方でも最大曲げモーメントは同じでしょうか。

**結論の見通し**　集中荷重と分布荷重を比べ、離散的な表で最大値を見落とす理由を説明します。

スライド38～53枚目 ／ 動画 56:14から

## Section 3.5　支え方を学校で比べる（視聴後・約10分）

**問い**　支え方の効果を確かめるには、何を変え、何をそろえるでしょうか。

**結論の見通し**　生徒の観察と、その背景にある力とモーメントのつり合いを結び付けます。

指導要領との接続を、[スライドPDF](03_授業スライド.pdf)の54～60枚目、または[ハンドアウト](03_ハンドアウト.pdf)の13～14頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド8：モーメントの計算に使う垂直距離と、斜めの長さを図で区別する。
- スライド18–19：全体から片側を切り出し、V（せん断力）・M（曲げモーメント）の正方向を確認する。ハンドアウト1–2頁を使う。
- スライド13–43：本編演習1–5。ハンドアウト3–7頁に外力図、途中式、線図を記録する。
- スライド24：集中荷重点の左右でVが跳ぶことと、Mが連続することを区別する。
- スライド40：分布荷重と合力は同じ部分の別の表し方。二つを同時に加えない。
- スライド41：表の6点の最大48 N·mと、連続モデルの最大50 N·mをグラフで比較する。
- スライド45–52：接続・想定問題1–4。ハンドアウト8–11頁を使う。AI回答を想定した検討文は本講義のオリジナル例です。AIの実利用は不要です。

この回の長さは主にm、モーメントはN·mです。共通記号一覧のN·mmとは換算が必要です（1 N·m = 1,000 N·mm）。外部の反力モーメントM_Aと、切断面の内部のMは、対象を分けて考えてください。

# Chapter 12（第12回）　複数の観点から材料を選ぶ

**この章の流れ**　要求条件と一次判定 → 寸法変更と定性的な比較 → 部位・加工・費用と環境 → 重み付けと提案の見直し → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 12.1　要求条件と一次判定

**問い**　材料の候補を絞る前に、何を必須条件にするでしょうか。

**結論の見通し**　必須条件を先に判定し、その後で候補の利点を比べます。

スライド2～10枚目 ／ 動画 01:15から（1枚目は章全体の導入）

### Section 12.2　寸法変更と定性的な比較

**問い**　候補が条件を外れたら、材料のほかに何を変えられますか。

**結論の見通し**　寸法を変えて再計算し、水に濡れる場面なども比べます。

スライド11～21枚目 ／ 動画 13:33から

### Section 12.3　部位・加工・費用と環境

**問い**　栽培設備の部位ごとに、どんな材料の役割があるでしょうか。

**結論の見通し**　容器・支持・接合を分け、製作から交換までを比べます。

スライド22～31枚目 ／ 動画 35:25から

### Section 12.4　重み付けと提案の見直し

**問い**　評価の重みを変えると、どこで候補の順位が入れ替わりますか。

**結論の見通し**　重みと得点の根拠を明示し、順位が変わる条件を確かめます。

スライド32～45枚目 ／ 動画 58:03から

## Section 12.5　複数の観点を使った選択（視聴後・約10分）

**問い**　複数の観点を使って材料を選んだ理由をどう説明しますか。

**結論の見通し**　必須条件を示し、優先した観点と残る課題を述べます。

指導要領との接続を、[スライドPDF](12_授業スライド.pdf)の46～52枚目、または[ハンドアウト](12_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

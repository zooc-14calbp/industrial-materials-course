# Chapter 12（第12回）　複数の観点から材料を選ぶ

**この章の流れ**　要求条件と一次判定 → 寸法変更と定性的な比較 → 部位・加工・費用と環境 → 重み付けと提案の見直し → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:47 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 12.1　要求条件と一次判定

**問い**　材料を選ぶとき、最初に何を満たす必要があるでしょうか。

**結論の見通し**　必須条件と望ましい条件を分け、同じ断面での計算を候補の一次判定に使います。

スライド1～9枚目 ／ 動画 00:00から

### Section 12.2　寸法変更と定性的な比較

**問い**　候補が条件を外れた場合、材種の変更以外に何ができるでしょうか。

**結論の見通し**　寸法を変えて再計算し、水との関わりなどを使用場面に即して説明します。

スライド10～19枚目 ／ 動画 13:14から

### Section 12.3　部位・加工・費用と環境

**問い**　栽培設備のすべてを同じ材料で作る必要はあるでしょうか。

**結論の見通し**　部位ごとの役割に合わせ、接合、測定への影響、交換を含む費用や環境条件を比べます。

スライド20～28枚目 ／ 動画 35:07から

### Section 12.4　重み付けと提案の見直し

**問い**　比較の重みを変えると、どこで結論が変わるでしょうか。

**結論の見通し**　順位の境界を確かめ、AIの提案や比較表を条件・根拠が見える形に直します。

スライド29～41枚目 ／ 動画 57:40から

## Section 12.5　複数の観点を使った選択（視聴後・約10分）

**問い**　材料に一つの総合順位を付ければ、どの用途にも使えるでしょうか。

**結論の見通し**　用途や制約から観点を選び、条件が変われば判断も見直します。

指導要領との接続を、[スライドPDF](12_授業スライド.pdf)の42～47枚目、または[ハンドアウト](12_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

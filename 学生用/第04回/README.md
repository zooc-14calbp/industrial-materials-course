# 第4回　断面の形と応力・たわみ

**学修時間の目安：約100分**（動画 89:40 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト](04_ハンドアウト.pdf)を用意する。全17頁。量と記号、平行軸の図、本編の計算と比較、接続・想定問題1–5、残差の記録、代表断面4頁、確認クイズ2頁、共通記号一覧です。
2. [授業動画（89:40）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson04-figures/lesson04-video.mp4)を見ながら、自分の説明を記録する。
3. [スライドPDF](04_授業スライド.pdf)で図・数値を確かめ、説明を見直す。[PowerPoint](04_授業スライド.pptx)にも対応原稿を入れています。

動画の実再生時間は89:40です。説明音声56:11、演習・休憩33:00、画面切替を含みます。合成音声・切替字幕付き。必要に応じて一時停止してください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](04_授業スライド.pdf)の53～58枚目、または[ハンドアウト](04_ハンドアウト.pdf)の15～16頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド9：図心軸と全体の軸、その間の垂直距離を図で確認する。ハンドアウト2頁を使う。
- スライド10–33：同じ板の向き、幅一定／面積一定の比較、応力とたわみの二条件。ハンドアウト3–4頁に記録する。
- スライド33：二つの荷重制限の共通範囲を確認し、選んだ値を式へ戻して検算する。
- スライド34：仮想測定値と理論値を重ねた図と、残差を拡大した図を比較する。横軸はいずれも荷重F（N）。左図はたわみδ（mm）を0～1.5 mm、右図は仮想測定値から理論値を引いた残差（mm）を0～0.03 mmの目盛りで示す。表の表示値とハンドアウト10頁で確かめる。
- スライド38–47：接続・想定問題1–5。ハンドアウト5–9頁を使う。AIの検討文は本講義の想定例であり、実際のサービスの出力ではありません。
- スライド49–52：正方形・長方形・円形・中空形・H断面の任意参考。動画本編には含めません。ハンドアウト11～14頁にも載っています。

PowerPoint・PDFは本編48枚、代表断面の任意参考4枚、指導要領と確認クイズ6枚の計58枚です。Iは断面二次モーメント（mm⁴）、Zは断面係数（mm³）、Eはヤング率（MPa）。この回のMは主にN·mmです。1 N·m = 1,000 N·mmに注意してください。

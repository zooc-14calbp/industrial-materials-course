# 指導要領との接続と確認クイズ

各回のスライド末尾とハンドアウトに、約10分の学習単元があります。動画で扱った原理を学校での学習に結び付ける復習です。動画内の演習を終えた後に取り組んでください。各回の案内に動画と確認クイズを合わせた所要時間を示しています。

要点を読み、資料を閉じて選択式2問と短い記述問題に答え、解説と比べてください。誤った箇所は理由を書き直し、次回にもう一度説明してみましょう。採点結果を提出する課題ではありません。

## 資料の位置付け

- **現行**：告示済みの学習指導要領と、その解説。校種・教科・項目を確認します。
- **審議資料**：次期改訂へ向けた検討。教科名・内容構成・実施時期を、告示済みの内容と混同しないようにします。
- **授業例・設問**：資料を踏まえて本講義で作成した提案。指導要領からの直接引用ではありません。

大学で学ぶ式や材料組織の説明は、教員として判断を支える専門的理解を含みます。そのまますべてを中学生に教えることを求めるものではありません。

## 改訂に向けた議論

第1・14・15回では、2026年10月の審議まとめに示された「情報・技術科」の改訂案を取り上げます。現行の技術・家庭科技術分野との区別を保ち、材料加工と情報・データの活用を結び付ける授業を考えます。将来の実施内容・時期は、その時点の正式な告示等で確認してください。

外部の解説記事や提言を追加する場合も、発信者・公表日・参照日を記録し、原資料と意見を区別します。

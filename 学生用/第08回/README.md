# Chapter 8（第8回）　プラスチックの加工・耐久性・資源循環

**この章の流れ**　形と数量に応じた成形 → 時間と環境による変化 → 原料由来と使用後の経路 → 製造から使用後までの提案 → 指導要領との接続・確認クイズ。

**学修時間の目安：約97分**（動画 87:29 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

1. [ハンドアウト（13頁）](08_ハンドアウト.pdf)を用意します。1頁に各節の見取り図、5～8頁に想定問題8問、9～10頁にクリープのグラフと生分解の条件を考える演習があります。
2. [授業動画（87:29）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-06-chapter08/lesson08-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](08_授業スライド.pdf) ／ [PowerPoint](08_授業スライド.pptx)で図と数値を確認します。

動画は87:29、合成音声・切替字幕付きです。必要に応じて一時停止してください。さらに復習する場合は、視聴後に5分程度、成形の違い、時間と変形、原料由来と生分解性、使用後の経路を図と自分の言葉で振り返ります。

## オンデマンド回の質問・意見交換

**意見交換の問い**　載荷後の変形を表す3点から言えることと、長期使用の判断に必要な追加データを比べる。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 8.1　形と数量に応じた成形

**問い**　栽培容器と断面が一定の管では、どんな作り方が向くでしょうか。

**結論の見通し**　樹脂の流れと工具の形を読み、製品の形や数量から成形法を考えます。

スライド2～10枚目 ／ 動画 00:26から（1枚目は章全体の導入）

### Section 8.2　時間と環境による変化

**問い**　同じ荷重をかけ続けると、栽培容器の変形はどうなるでしょうか。

**結論の見通し**　時間とともに進む変形を読み、温度や日射などの使用条件を確かめます。

スライド11～18枚目 ／ 動画 06:59から

### Section 8.3　原料由来と使用後の経路

**問い**　植物由来の樹脂は、どんな環境でも生分解するでしょうか。

**結論の見通し**　原料由来と生分解性を別々に確かめ、回収先と受入条件を調べます。

スライド19～29枚目 ／ 動画 15:11から

### Section 8.4　製造から使用後までの提案

**問い**　栽培容器の案を見直すとき、どの段階の条件を確かめますか。

**結論の見通し**　作り方、使用時の変形、使用後の経路を、提案の理由に結び付けます。

スライド30～47枚目 ／ 動画 29:00から

## Section 8.5　プラスチックの使用後を考える（視聴後・約10分）

**問い**　使用済みの容器をどう扱うか、生徒と何を調べますか。

**結論の見通し**　使い方と回収先を確かめ、再使用や再資源化の条件を説明します。

指導要領との接続を、[スライドPDF](08_授業スライド.pdf)の48～54枚目、または[ハンドアウト](08_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

# 第8回 プラスチックの加工・耐久性・資源循環

**学修時間の目安：約96分**（動画 85:55 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（13頁）](08_ハンドアウト.pdf)を用意します。既存の想定問題8問に加え、9～10頁に時間による変形と生分解の条件を考える記録欄があります。
2. [授業動画（85:55）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson08-listening/lesson08-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](08_授業スライド.pdf) ／ [PowerPoint](08_授業スライド.pptx)で図と数値を確認します。

動画は85:55、合成音声・切替字幕付きです。必要に応じて一時停止してください。さらに復習する場合は、視聴後に5分程度、成形の違い、時間と変形、原料由来と生分解性、使用後の経路を図と自分の言葉で振り返ります。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](08_授業スライド.pdf)の44～49枚目、または[ハンドアウト](08_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド6：真空成形での大気圧と排気。
- スライド10・12：クリープの変形前後、仮想データの時間軸。ハンドアウト9頁。
- スライド17～19：原料由来と生分解性、生分解の条件、再使用と各経路。ハンドアウト10頁。
- スライド27～42：教員採用試験を意識した想定問題8問。実際の過去問の転載や出題予告ではなく、正式な提出課題とも別です。

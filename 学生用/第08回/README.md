# Chapter 8（第8回）　プラスチックの加工・耐久性・資源循環

**この章の流れ**　形と数量に応じた成形 → 時間と環境による変化 → 原料由来と使用後の経路 → 製造から使用後までの提案 → 指導要領との接続・確認クイズ。

**学修時間の目安：約96分**（動画 85:55 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

1. [ハンドアウト（13頁）](08_ハンドアウト.pdf)を用意します。既存の想定問題8問に加え、9～10頁に時間による変形と生分解の条件を考える記録欄があります。

3. [スライドPDF](08_授業スライド.pdf) ／ [PowerPoint](08_授業スライド.pptx)で図と数値を確認します。

動画は85:55、合成音声・切替字幕付きです。必要に応じて一時停止してください。さらに復習する場合は、視聴後に5分程度、成形の違い、時間と変形、原料由来と生分解性、使用後の経路を図と自分の言葉で振り返ります。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 8.1　形と数量に応じた成形

**問い**　製品の形に合わせて、どの成形法を選べるでしょうか。

**結論の見通し**　射出・押出・熱成形・積層造形を、材料の流れ、形、接合方法から比べます。

スライド1～9枚目 ／ 動画 00:00から

### Section 8.2　時間と環境による変化

**問い**　最初は十分に硬い容器でも、使用中に何が起こり得るでしょうか。

**結論の見通し**　クリープによる長期変形と日射・熱・水などの影響を分け、点検条件を考えます。

スライド10～16枚目 ／ 動画 06:35から

### Section 8.3　原料由来と使用後の経路

**問い**　植物由来であれば、どの環境でも分解するのでしょうか。

**結論の見通し**　原料由来と生分解性を別の軸にし、使用後の回収・再使用・再資源化を条件付きで比べます。

スライド17～26枚目 ／ 動画 14:25から

### Section 8.4　製造から使用後までの提案

**問い**　栽培容器の案を、製造・使用・使用後のどこから見直せるでしょうか。

**結論の見通し**　成形条件、長期データの限界、処理先を組み合わせ、提案と根拠を示します。

スライド27～43枚目 ／ 動画 27:51から

## Section 8.5　プラスチックの使用後を考える（視聴後・約10分）

**問い**　環境面から材料を選ぶには、何を先に確かめるでしょうか。

**結論の見通し**　原料と分解条件を区別し、製造・使用・使用後の経路を考えます。

指導要領との接続を、[スライドPDF](08_授業スライド.pdf)の44～49枚目、または[ハンドアウト](08_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

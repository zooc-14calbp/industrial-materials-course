# 第2回　単位・力・応力・ひずみ

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト](02_ハンドアウト.pdf)を用意する。全13頁。量と記号、Eとkの比較、本編演習1–5、接続・想定問題1–4、追加自己確認、共通記号一覧です。
2. [授業動画（89:58）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-90min/lesson02-video.mp4)を見ながら、自分の説明を記録する。
3. [スライドPDF](02_授業スライド.pdf)で図・数値を確かめ、説明を見直す。[PowerPoint](02_授業スライド.pptx)にも対応原稿を入れています。

動画の実再生時間は89:58です。説明音声63:13、演習・休憩26:11と画面切替を含みます。合成音声・切替字幕付き。必要に応じて一時停止してください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](02_授業スライド.pdf)の58～63枚目、または[ハンドアウト](02_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド23–30：応力・ひずみ・伸びを区別し、式の名称と単位を確認する。
- スライド31：E（材料のヤング率）とk（棒の軸方向の剛性）を二つのグラフで比べる。ハンドアウト2頁を使う。
- スライド33–47：本編の演習1–5。ハンドアウト3–5頁に途中式・単位・判断を記録する。
- スライド49–56：接続・想定問題1–4。ハンドアウト6–9頁を使う。AIの実利用は不要です。
- スライド54：仮想測定値の原点と傾きを区別する。グラフの直線を延長した値と実測値を分けて考える。

例題ごとにEの設定値が異なります。206,000 MPaの演習と200,000 MPaの比較例を混ぜず、その画面の条件を使ってください。

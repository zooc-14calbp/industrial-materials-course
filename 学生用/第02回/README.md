# Chapter 2（第2回）　単位・力・応力・ひずみ

**この章の流れ**　質量・力・応力の単位 → 力のかかり方と断面 → 材料のヤング率と部材の剛性 → 変形の限界と計算の点検 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 2.1　質量・力・応力の単位

**問い**　kg、N、Paはそれぞれ何を表すのでしょうか。

**結論の見通し**　質量・力・面積当たりの力を区別し、単位をそろえて検算します。

スライド2～13枚目 ／ 動画 00:50から（表紙は1枚目）

### Section 2.2　力のかかり方と断面

**問い**　外からかけた力は、部材のどこを通って支えに届くでしょうか。

**結論の見通し**　荷重経路をたどり、断面の平均垂直応力と、伸びを長さで割ったひずみを求めます。

スライド14～28枚目 ／ 動画 13:20から

### Section 2.3　材料のヤング率と部材の剛性

**問い**　同じ材料の棒でも、長さや太さで伸び方が変わるのはなぜでしょうか。

**結論の見通し**　ヤング率Eと軸方向の剛性kを分け、線形弾性の範囲で伸びを計算します。

スライド29～44枚目 ／ 動画 30:03から

### Section 2.4　変形の限界と計算の点検

**問い**　応力と伸びに上限があるとき、荷重はどこまで増やせるでしょうか。

**結論の見通し**　弾性と塑性を区別し、二つの制限と単位、入力条件を式に戻して確かめます。

スライド45～61枚目 ／ 動画 57:24から

## Section 2.5　力と変形を学校で扱う（視聴後・約10分）

**問い**　同じ力をかけた観察から、何を説明できるでしょうか。

**結論の見通し**　条件をそろえた観察と、応力・ひずみで理由を説明する教師の理解をつなぎます。

指導要領との接続を、[スライドPDF](02_授業スライド.pdf)の62～68枚目、または[ハンドアウト](02_ハンドアウト.pdf)の11～12頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド25–33：応力・ひずみ・伸びを区別し、式の名称と単位を確認する。

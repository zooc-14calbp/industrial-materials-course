# Chapter 14（第14回）　技術科・他領域へつなぐ教材設計

**この章の流れ**　現行の学習と次期改訂の議論 → 題材・到達目標・活動の対応 → 専門知識と学習の準備 → 生徒の説明と教材の見直し → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（13頁）](14_ハンドアウト.pdf)を用意します。冒頭の「節の見取り図」から進み、演習とクイズは本文に印刷されたページ番号で確認します。9頁に関連領域と授業の問いの記録欄があります。
2. [授業動画（89:58）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-06-chapters09-15/lesson14-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](14_授業スライド.pdf) ／ [PowerPoint](14_授業スライド.pptx)で内容を確認します。

動画は89:58、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## オンデマンド回の質問・意見交換

**意見交換の問い**　栽培容器を支える題材で生徒に何を説明してもらうかを示し、活動と記録が目標に合うかを比べる。

担当教員がオンデマンド実施を案内した回は、学内システムの第14回の案内から質問・意見交換に進んでください。教員は回答や学修記録を確認し、授業後速やかに質問への回答や必要な補足を案内します。[授業の進め方と学習支援](../../授業方法と学習支援.md)

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 14.1　現行の学習と次期改訂の議論

**問い**　現行の指導内容と次期改訂の審議資料を、どう読み分けますか。

**結論の見通し**　公表主体・日付・資料の位置付けを確かめ、授業案と区別します。

スライド2～9枚目 ／ 動画 00:50から（1枚目は章全体の導入）

### Section 14.2　題材・到達目標・活動の対応

**問い**　栽培容器を支える題材で、生徒に何を説明してもらいますか。

**結論の見通し**　題材の役割を分け、学習目標を比較活動と記録に結び付けます。

スライド10～17枚目 ／ 動画 20:06から

### Section 14.3　専門知識と学習の準備

**問い**　大学で学んだ式や数値を、学校の活動にどう生かしますか。

**結論の見通し**　教師の試作・判断に専門知識を使い、生徒には比較できる条件を用意します。

スライド18～23枚目 ／ 動画 50:13から

### Section 14.4　生徒の説明と教材の見直し

**問い**　生徒の説明を読んだら、何を確かめ、どう問い返しますか。

**結論の見通し**　選択理由と比較条件を読み取り、追加で確認できる問いを返します。

スライド24～31枚目 ／ 動画 01:07:30から

## Section 14.5　現行と審議案を踏まえた授業設計（視聴後・約10分）

**問い**　材料の授業でデータを使うとき、学習目標をどう定めますか。

**結論の見通し**　資料の位置付けを区別し、活動と生徒が示す根拠を対応させます。

指導要領との接続を、[スライドPDF](14_授業スライド.pdf)の32～39枚目、または[ハンドアウト](14_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

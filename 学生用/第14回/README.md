# Chapter 14（第14回）　技術科・他領域へつなぐ教材設計

**この章の流れ**　現行の学習と次期改訂の議論 → 題材・到達目標・活動の対応 → 専門知識と学習の準備 → 生徒の説明と教材の見直し → 指導要領との接続・確認クイズ。

**学修時間の目安：約99分**（動画 88:55 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（12頁）](14_ハンドアウト.pdf)を用意します。9頁に関連領域と授業の問いの記録欄があります。
2. [授業動画（88:55）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson14-listening/lesson14-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](14_授業スライド.pdf) ／ [PowerPoint](14_授業スライド.pptx)で内容を確認します。

動画は88:55、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 14.1　現行の学習と次期改訂の議論

**問い**　材料とものづくりは、現行の学習と次期の審議資料でどう扱われるでしょうか。

**結論の見通し**　資料の位置付けを区別し、デジタル化しても材料や使用の条件が残ることを確かめます。

スライド1～8枚目 ／ 動画 00:00から

### Section 14.2　題材・到達目標・活動の対応

**問い**　栽培容器を支える題材で、生徒に何を説明できるようにするでしょうか。

**結論の見通し**　関連領域の問いを分け、目標を比較活動と記録に対応させます。

スライド9～15枚目 ／ 動画 19:49から

### Section 14.3　専門知識と学習の準備

**問い**　大学で扱った式や数値を、学校の活動にどう移すでしょうか。

**結論の見通し**　専門の式は教師の判断に生かし、生徒には観察と図・記録から説明する機会をつくります。

スライド16～20枚目 ／ 動画 49:45から

### Section 14.4　生徒の説明と教材の見直し

**問い**　生徒の説明を読んだとき、何を確かめ、どう問い返すでしょうか。

**結論の見通し**　選択の根拠と比較条件を読み取り、評価・改善と制度資料の更新につなげます。

スライド21～27枚目 ／ 動画 01:06:42から

## Section 14.5　現行と審議案を踏まえた授業設計（視聴後・約10分）

**問い**　材料の授業にデータ活用を加えるとき、目標をどう定めるでしょうか。

**結論の見通し**　現行の根拠と改訂の議論を分け、活動と生徒が示す根拠を対応させます。

指導要領との接続を、[スライドPDF](14_授業スライド.pdf)の28～34枚目、または[ハンドアウト](14_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

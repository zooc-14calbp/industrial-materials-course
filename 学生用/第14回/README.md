# 第14回 技術科・他領域へつなぐ教材設計

**学修時間の目安：約99分**（動画 88:55 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 動画で学ぶ

1. [ハンドアウト（12頁）](14_ハンドアウト.pdf)を用意します。9頁に関連領域と授業の問いの記録欄があります。
2. [授業動画（88:55）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-lesson14-listening/lesson14-video.mp4)を視聴し、図と説明を対応させて記録します。
3. [スライドPDF](14_授業スライド.pdf) ／ [PowerPoint](14_授業スライド.pptx)で内容を確認します。

動画は88:55、合成音声・切替字幕付きです。必要に応じて一時停止して取り組んでください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](14_授業スライド.pdf)の28～34枚目、または[ハンドアウト](14_ハンドアウト.pdf)の10～11頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

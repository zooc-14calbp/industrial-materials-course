# 第6回　金属の加工・熱処理・使用環境

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

1. [ハンドアウト](06_ハンドアウト.pdf)を用意する。全13頁。量と記号、熱処理、穴あき板、栽培架台、観察課題、想定問題8問、点検データとAI評価の記録欄です。
2. [授業動画（89:58）](https://github.com/zooc-14calbp/industrial-materials-course/releases/download/2026-11-02-90min/lesson06-video.mp4)を見ながら、自分の説明を記録する。
3. [スライドPDF](06_授業スライド.pdf)で図・数値を確かめ、説明を見直す。[PowerPoint](06_授業スライド.pptx)にも対応原稿を入れています。

動画の実再生時間は89:58です。説明音声39:06、演習・休憩50:25と画面切替を含みます。合成音声・切替字幕付き。必要に応じて一時停止してください。

## 視聴後の確認クイズ（約10分）

指導要領との接続を、[スライドPDF](06_授業スライド.pdf)の46～51枚目、または[ハンドアウト](06_ハンドアウト.pdf)の12～13頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド6–13：冷間加工、焼なまし・焼ならし、焼入れ・焼戻し。温度履歴と処理前後の状態をつなぐ。ハンドアウト1–2頁。
- スライド17–19：正面図と切断面を対応させ、全断面と正味断面の平均応力を比較する。ハンドアウト3頁。
- スライド20–26：表面・接合部・使用環境・維持の条件から栽培架台を提案する。ハンドアウト4・11頁。
- スライド27–28：加工の観察と比較。ハンドアウト5–6頁。
- スライド29–44：教員採用試験を意識した想定問題8問。ハンドアウト7–10頁。実際の過去問の転載・出題予告ではありません。

PowerPoint・PDFは動画に対応する本編45枚と、指導要領と確認クイズ6枚の計51枚です。Fは軸力、bは幅、dは穴径、tは厚さ、σは垂直応力です。平均応力を計算するときは、どの断面積で平均した量かを示します。熱処理の図は、実際の温度・時間を指示するものではありません。

動画内の考える時間に図・条件・理由を記録します。必要に応じて一時停止し、最後に焼入れと焼戻し、全断面と正味断面、観察結果と使用の判断の違いを説明してください。

評価課題は4回構成の共有案です。配点・提出期限・提出先は、担当教員の正式な告知を確認してください。動画内の自己確認は、個別の提出課題ではありません。

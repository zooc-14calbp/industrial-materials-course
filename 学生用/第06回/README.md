# Chapter 6（第6回）　金属の加工・熱処理・使用環境

**この章の流れ**　加工と熱処理の目的 → 切削・接合と穴のある断面 → 腐食と屋外での材料選択 → 加工図の観察と条件の適用 → 指導要領との接続・確認クイズ。

**学修時間の目安：約100分**（動画 89:58 ＋ 確認クイズ 約10分）。動画には演習や休憩の時間が含まれます。一時停止して取り組む時間やレポートの時間は別に見込んでください。

90分を目安に学ぶ場合は、先に動画と動画内の演習に取り組み、確認クイズは授業外の復習に回せます。授業で進め方の指定がある場合は、その指示に従ってください。

## 本編のSection

各節に入る前に「問い」と「結論の見通し」を読み、対応するスライドと動画へ進んでください。

### Section 6.1　加工と熱処理の目的

**問い**　刃物を作るときと使うときでは、何が求められるでしょうか。

**結論の見通し**　形や組織の変化を、加工と熱処理の目的に結び付けます。

スライド2～14枚目 ／ 動画 00:37から（1枚目は章全体の導入）

### Section 6.2　切削・接合と穴のある断面

**問い**　穴のある板を引くとき、力を伝える面積はどこで測るでしょうか。

**結論の見通し**　穴を通る切断面を描き、全断面と正味断面の平均応力を比べます。

スライド15～21枚目 ／ 動画 16:09から

### Section 6.3　腐食と屋外での材料選択

**問い**　屋外の栽培架台で、水が残りやすい場所をどう見つけるでしょうか。

**結論の見通し**　材種と表面処理に加え、接合部の形、排水、点検のしやすさを比べます。

スライド22～29枚目 ／ 動画 24:45から

### Section 6.4　加工図の観察と条件の適用

**問い**　加工の図から分かることと、追加で調べることは何でしょうか。

**結論の見通し**　工具・材料・力の向きを読み、判断に必要な条件を考えます。

スライド30～49枚目 ／ 動画 34:03から

## Section 6.5　加工前後の違いを説明する（視聴後・約10分）

**問い**　学校の加工の学習で、操作と材料の変化をどうつなげるでしょうか。

**結論の見通し**　加工前後の形や性質を比べ、違いを加工の目的と結び付けます。

指導要領との接続を、[スライドPDF](06_授業スライド.pdf)の50～56枚目、または[ハンドアウト](06_ハンドアウト.pdf)の12～13頁で学びます。

要点を読んだら資料を閉じ、選択式2問と記述1問に答えてから、解答と理由を確認してください。前の回を思い出す問いもあります。クイズは自己確認用です。[出典の区分とクイズの使い方](../共通補助資料/指導要領との接続/README.md)も参照できます。

## 図・演習の参照先

- スライド7–14：冷間加工、焼なまし・焼ならし、焼入れ・焼戻し。温度履歴をたどり、処理前の組織と得たい性質を比べる。ハンドアウト1–2頁。
- スライド19–21：正面図と切断面を対応させ、全断面と正味断面の平均応力を比較する。ハンドアウト3頁。
- スライド22–29：表面・接合部・使用環境・維持の条件から栽培架台を提案する。ハンドアウト4・11頁。
- スライド31–32：加工の観察と比較。ハンドアウト5–6頁。
- スライド33–48：教員採用試験を意識した想定問題8問。ハンドアウト7–10頁。実際の過去問の転載・出題予告ではありません。

PowerPoint・PDFは動画に対応する本編49枚と、指導要領と確認クイズ7枚の計56枚です。Fは軸力、bは幅、dは穴径、tは厚さ、σは垂直応力です。平均応力を計算するときは、どの断面積で平均した量かを示します。熱処理の図は、実際の温度・時間を指示するものではありません。

動画内の考える時間に図・条件・理由を記録します。必要に応じて一時停止し、最後に焼入れと焼戻し、全断面と正味断面、観察結果と使用の判断の違いを説明してください。
